# Разметка типов нарушений — инструкция (30–45 минут на человека)

## Зачем это нужно

В датасете есть метка «нарушение» и секунда, но **тип не указан** (п.2 FAQ). Без типа:
- нельзя построить признак под каждый тип (критерий 1 — 25 баллов, критерий 3 — 15 баллов);
- нельзя проверить, что сервис назвал событие правильно.

Я (Claude) просмотрел кадры вокруг размеченных секунд и по половине роликов тип определить
не смог: на 464×848 сверху «пересчёт денег руками» и «работа с бумагой» выглядят одинаково.
Человек, отматывающий видео в плеере, определяет это за полминуты. Это самая ценная задача на ночь.

## Как размечать

1. Открыть ролик в QuickTime / VLC, перемотать на `секунда - 3`.
2. Проиграть до `секунда + 3` **покадрово** (в QuickTime — стрелки влево/вправо).
3. Записать в `labels.csv` (разделитель `;`):

| поле | что писать |
|---|---|
| `video` | имя файла без расширения, как в таблице |
| `sec` | размеченная секунда (уже проставлена) |
| `type` | код типа из списка ниже |
| `what` | что конкретно происходит, своими словами, 5–15 слов |
| `cue` | **что именно на экране это доказывает** — предмет, место, действие |
| `conf` | `high` / `med` / `low` — насколько уверены |

4. Если на размеченной секунде ничего особенного не видно — посмотреть весь ролик целиком
   и написать `type=unclear`, а в `what` — что вообще происходит в ролике. Это тоже результат:
   значит, признак не визуальный, и его надо исключить из обещаний сервиса.

## Коды типов

| код | тип |
|---|---|
| `manual_count` | пересчёт наличных руками, счётно-денежная машина не используется |
| `cash_unattended` | наличные лежат на столе, кассир не контролирует их |
| `cash_handover` | деньги переданы из рук в руки / положены на стол мимо лотка |
| `left_workplace` | кассир ушёл с рабочего места, не убрав ценности |
| `cabin_open` | дверь кассовой кабины открыта / кабина не заперта |
| `safe_open` | сейф или шкаф оставлен открытым |
| `outsider` | посторонний в кассовом помещении во время операции с наличными |
| `food_drink` | стакан, кружка, банка, бутылка, еда на рабочем месте |
| `personal_bag` | личная сумка, рюкзак, пакет на рабочем месте |
| `sealed_bag` | инкассаторская сумка вне сейфа / передана без оформления |
| `phone_use` | кассир пользуется телефоном на рабочем месте |
| `other` | другое — обязательно описать в `what` |
| `unclear` | на видео не видно, что именно нарушено |

## Что важно

- **Не угадывать.** `unclear` — нормальный и полезный ответ. Выдуманный тип хуже отсутствующего:
  по нему будет построено правило, которое даст ложные срабатывания на проверке жюри.
- В поле `cue` писать максимально физически: не «нарушение кассовой дисциплины»,
  а «зелёная сумка лежит на столешнице, кассир стоит у стеклянной стены в 2 м от стола».
- Если в ролике **несколько** событий — добавить вторую строку с той же `video` и своей `sec`.
  (Так уже известно про `Х-4`: размечен дважды, на 57 и 68 секунде.)
